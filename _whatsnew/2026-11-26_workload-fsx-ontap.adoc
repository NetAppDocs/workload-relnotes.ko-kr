:allow-uri-read: 




[[new-recommendations-for-storage-vm-name-services]]
=== 스토리지 VM 네임 서비스에 대한 새로운 권장 사항

Workload Factory는 이제 잘 설계된 아키텍처 분석에서 스토리지 VM 이름 서비스에 대해 다음과 같은 권장 사항을 포함합니다:

*DNS 및 LDAP 서버 이중화*: DNS를 사용하는 스토리지 VM에는 최소 2개의 DNS 서버를, LDAP를 사용하는 스토리지 VM에는 최소 2개의 LDAP 서버를 권장합니다. 단일 서버 장애로 인해 이름 확인, 도메인 인증 또는 NFS 액세스가 차단될 수 있습니다.



[[volumes-explorer-enhancements]]
=== 볼륨 탐색기 개선 사항



==== 새 볼륨 탐색기 테이블 열

볼륨 탐색기 테이블에 다음과 같은 새 열이 추가되었습니다.

* *논리적 사용 크기*: 스토리지 효율성 절감 전, 클라이언트가 사용 중인 것으로 인식하는 공간을 보여줍니다. 이 열은 기본적으로 표시됩니다.
* *접합 경로*: 볼륨의 접합 경로를 보여줍니다.




==== 볼륨 탐색기에서 마운트 지점 관리

이제 볼륨 탐색기에서 스토리지 VM 네임스페이스의 볼륨 마운트 위치를 직접 관리할 수 있습니다. 볼륨의 *Advanced* 메뉴에서 *Manage mount points*를 선택하여 스토리지 VM 네임스페이스를 트리 구조로 확인한 다음, 볼륨을 마운트, 마운트 해제하거나 마운트 지점(접합 경로)을 변경할 수 있습니다. Workload Factory는 볼륨을 마운트 해제하기 전에 종속성을 확인합니다. 다른 볼륨이 마운트된 볼륨은 마운트 해제할 수 없으며, 해당 볼륨에 SMB 공유가 있는 경우 경고가 표시됩니다.

link:https://docs.netapp.com/us-en/workload-fsx-ontap/manage-volume-settings.html["마운트 포인트를 관리하는 방법을 알아보세요"]



==== 새 볼륨에 대한 중첩된 접합 경로

볼륨을 생성할 때 이제 *고급 구성* 섹션에서  `/test1/test2` 등과 같은 중첩 정션 경로를 입력할 수 있습니다.

link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-volume.html["볼륨을 만드는 방법을 알아보세요"] === 사용자 지정 규칙 사용자 지정 규칙은 *Well-architected* > *사용자 지정 규칙*에서 사용할 수 있으며, 잘 설계된 구성에서 규칙을 시작하고 예약된 실행이 완료되면 알림을 받을 수 있습니다.



==== 잘 설계된 구성을 사용자 지정 규칙으로 맞춤 설정하십시오.

원래의 모범 사례를 유지하면서 자체 임계값 또는 범위를 적용할 수 있도록 잘 설계된 구성에서 사용자 지정 규칙을 시작할 수 있습니다. Workload Factory는 해당 구성을 기반으로 편집 가능한 프롬프트와 함께 사용자 지정 규칙을 엽니다. 규칙은 초안으로 시작되며, 설명에는 어떤 구성을 기반으로 하는지 명시됩니다. link:https://docs.netapp.com/us-en/workload-fsx-ontap/improve-configurations.html["잘 설계된 구성 사용자 지정에 대해 자세히 알아보기"]



==== 예약된 사용자 지정 규칙 실행에 대한 알림 수신

Workload Factory에 로그인하지 않고도 결과를 확인하려면 예약된 사용자 지정 규칙에 대한 알림을 켜십시오. 예약된 실행 후 매번 알림을 받거나 실행이 실패하거나 부분적으로 성공했을 때만 알림을 받을 수 있습니다. 알림은 이미 설정한 채널을 통해 전송됩니다. 수동 테스트는 알림을 보내지 않습니다. link:https://docs.netapp.com/us-en/workload-fsx-ontap/manage-custom-rules.html["예약된 사용자 지정 규칙에 대한 알림에 대해 자세히 알아보세요"]
